# Flora Operations Knowledge

Folder ini mendokumentasikan seluruh proses operasional Masjid Munzalan Mubarakan As-Samad Balikpapan.

AI Agent wajib mengikuti SOP yang terdapat pada folder ini sebelum mengambil tindakan.

Area operasional meliputi:

- Daily Operations
- Content Pipeline
- Fundraising
- Social Media
- Reporting
- Meeting
- Checklist
- Automation

Tujuan folder ini adalah memastikan seluruh AI Agent bekerja dengan standar yang sama, konsisten, terdokumentasi, dan dapat terus dikembangkan.
