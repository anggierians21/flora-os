# Flora Program Knowledge Base

Folder ini berisi seluruh pengetahuan mengenai program-program yang dijalankan oleh Masjid Munzalan Mubarakan As-Samad Balikpapan.

Program yang terdokumentasi:

- Wakaf Pembangunan dan Pengembangan Kawasan Masjid
- Wakaf Produktif
- ZIS (Zakat, Infak, Sedekah)
- Water Treatment Plant (WTP) (wakaf produktif)
- TPQ
- Kajian
- Kemakmuran Masjid
- Media & Content
- PASKAS

Setiap file minimal memuat:

- Tujuan Program
- Latar Belakang
- Target Penerima Manfaat
- Target Donatur/Wakif
- Aktivitas Program
- SOP Ringkas
- KPI
- FAQ
- Ide Konten
- Peluang Pengembangan

Seluruh AI Agent Flora WAJIB membaca file yang relevan sebelum memberikan rekomendasi, membuat konten, atau menyusun strategi.
